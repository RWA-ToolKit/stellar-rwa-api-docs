# Filtering and sorting assets

<LastReviewed date={metadata.lastReviewed} />

`GET /v1/assets` accepts these query parameters:

| Parameter | Values | Description |
| --- | --- | --- |
| `asset_type` | e.g. `real_estate` | Only assets of this class. |
| `active` | `true`, `false` | Only active or inactive assets. |
| `sort` | `valuation` | Sort by USD valuation (ordered by `valuation_cents` in USD cents). |
| `order` | `asc`, `desc` (default) | Direction; requires `sort`. |
| `fields` | comma-separated field names | Return only these fields (partial response). |
| `offset`, `limit` | integers | Pagination (limit defaults to 50, max 100). |

```bash
curl "$API_BASE_URL/v1/assets?asset_type=real_estate&sort=valuation&order=asc"
```

Invalid or unknown parameters return `400` with the shared error body:

```json
{
  "error": {
    "code": "bad_request",
    "message": "unknown query parameter: foo"
  }
}
```

See [API · Error Bodies](/docs/api/errors) for the canonical error shape and the full list of error codes.

## Empty results

When no assets match the supplied filters, `GET /v1/assets` returns `200` with
an empty JSON array — never `null` and never an error:

```json
[]
```

```bash
curl "$API_BASE_URL/v1/assets?asset_type=real_estate&active=false"
# 200 OK
# []
```

Malformed or out-of-range parameters (for example a non-integer `limit`, an
unknown `sort` value, or `order` without `sort`) still return `400` with the
shared error body `{"error": "invalid_parameter", "message": "..."}` — an empty
result set is only returned for valid parameters that match nothing.

## Field selection

Combine `?fields=` with the filter and sort parameters to trim each item in the
response to just the fields you need. Filtering and sorting still apply to the
full record set before the projection is applied.

```bash
curl "$API_BASE_URL/v1/assets?asset_type=real_estate&sort=valuation&order=asc&fields=id,symbol,valuation_usd"
```

An unknown field name returns `400` with a body of the form:

```json
{"error": "invalid_parameter", "message": "unknown field ..."}
```

See [API · Field Selection](/docs/api/field-selection) for the full list of
selectable fields and projection rules.
