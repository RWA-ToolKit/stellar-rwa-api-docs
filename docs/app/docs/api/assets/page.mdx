## List assets

<ApiEndpoint method="GET" path="/assets" description="All tokenized assets with valuation, supply and holder counts." />

Returns an array of asset objects.

**Query parameters** (all optional)

| Name | Type | Notes |
|------|------|-------|
| `asset_type` | string | Filter by class: `real_estate`, `invoice`, `commodity` |
| `active` | boolean | Filter by active status |
| `fields` | string | Sparse fieldset: comma-separated list such as `id,name,active`. |
| `offset` | integer | Skip the first N matching assets. Default: `0`. |
| `limit` | integer | Page size. Default: `50`; maximum: `100`. |

Results are paginated to keep large collections bounded. Use `offset` and `limit` together to walk the list in chunks.

```bash
curl "$API_BASE_URL/assets?asset_type=real_estate&active=true&offset=0&limit=50"
```

**Response schema** (per asset):

| Field | Type | Notes |
|-------|------|-------|
| `id` | number | Registry id |
| `token_contract` | string | Asset-token contract |
| `issuer` | string | Issuer account |
| `name` | string | |
| `symbol` | string | |
| `asset_type` | string | `real_estate` \| `invoice` \| `commodity` |
| `description` | string | |
| `valuation_cents` | string | Valuation in **USD cents** (`i128` string). Divide by 100 to get USD dollars. |
| `valuation_usd` | number | Valuation in **USD dollars** (`f64` convenience float, equal to `valuation_cents / 100`). |
| `decimals` | number | Number of decimal places used by this asset token (e.g. `2`). |
| `total_supply` | string | Total supply in **base units** (`i128` string in the token's `decimals` base). Divide by `10 ** decimals` to get the human-readable token amount. |
| `holders` | number | Addresses with a positive balance |
| `active` | boolean | |
| `paused` | boolean | |
| `compliance_contract` | string | Gate for this asset |
| `created_at_ledger` | number | |
| `indexed_at_ledger` | number | Most recent ledger successfully indexed for this asset |
| `index_error` | string or null | Per-asset index error, if the latest refresh failed |
**Response schema** (`Asset`, per asset):

| Field | Type | Unit | Nullable | Description |
|-------|------|------|----------|-------------|
| `id` | integer | Registry id | No | |
| `token_contract` | string | — | No | Asset-token contract address |
| `issuer` | string | — | No | Issuer account address |
| `name` | string | — | No | |
| `symbol` | string | — | No | |
| `asset_type` | string | — | No | `real_estate`, `invoice`, or `commodity` |

| `valuation_usd` | number | USD | No | Convenience valuation in dollars |
| `decimals` | integer | Decimal places | No | Token precision for converting base units |
| `total_supply` | string | Asset-token base units | No | Exact supply (`i128` serialized as a decimal string) |
| `holders` | integer | Addresses | No | Addresses with a positive balance |

## Get an asset

<ApiEndpoint method="GET" path="/assets/:id" description="Full detail for a single asset by registry id." />

**Path parameters**

| Name | Type | Notes |
|------|------|-------|
| `id` | number | Registry id (e.g. `1`) |

**Example**

```bash
curl $API_BASE_URL/v1/assets/1
```

Returns a single asset object with the schema above.

You can also request a sparse fieldset with `?fields=`; for example:

```bash
curl "$API_BASE_URL/v1/assets/1?fields=id,name,active,indexed_at_ledger"
```

**Errors**

```json
{ "error": "not_found", "message": "no asset with id 999" }
```

Returned with status `404` when no asset has the given id. A non-numeric id
(`/assets/abc`) is rejected with `400` by the router.

<CalloutBox variant="tip" title="Amount units and conversions">
Both `total_supply` and `valuation_cents` are 128-bit integers returned as strings to prevent rounding in JavaScript runtimes.

```typescript
// 1. Converting total_supply (base units to display tokens):
// Given total_supply = "1000000" and decimals = 2:
const rawSupply = BigInt(asset.total_supply);
const displaySupply = Number(rawSupply) / (10 ** asset.decimals);
// => 10,000.00 MLOFT

// 2. Converting valuation_cents (USD cents to USD dollars):
// Given valuation_cents = "500000000":
const rawCents = BigInt(asset.valuation_cents);
const displayUsd = Number(rawCents) / 100;
// => 5000000.00 ($5,000,000.00 USD)
```
</CalloutBox>
