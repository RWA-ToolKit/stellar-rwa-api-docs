# Assets

## List assets

<ApiEndpoint method="GET" path="/assets" description="All tokenized assets with valuation, supply and holder counts." />

Returns an array of asset objects.

**Query parameters** (all optional)

| Name | Type | Notes |
|------|------|-------|
| `asset_type` | string | Filter by class: `real_estate`, `invoice`, `commodity` |
| `active` | boolean | Filter by active status |

```bash
curl "http://localhost:8080/assets?asset_type=real_estate&active=true"
```

**Response schema** (per asset):

| Field | Type | Notes |
|-------|------|-------|
| `id` | number | Registry id |
| `token_contract` | string | Asset-token contract |
| `issuer` | string | Issuer account |
| `name` | string | |
| `symbol` | string | |
| `asset_type` | string | `real_estate` \| `invoice` \| `commodity` |
| `description` | string | |
| `valuation_cents` | string | USD cents (`i128`) |
| `valuation_usd` | number | Dollars, convenience |
| `decimals` | number | |
| `total_supply` | string | Base units (`i128`) |
| `holders` | number | Addresses with a positive balance |
| `active` | boolean | |
| `paused` | boolean | |
| `compliance_contract` | string | Gate for this asset |
| `created_at_ledger` | number | |

**Example**

```bash
curl http://localhost:8080/assets
```

## Get an asset

<ApiEndpoint method="GET" path="/assets/:id" description="Full detail for a single asset by registry id." />

**Path parameters**

| Name | Type | Notes |
|------|------|-------|
| `id` | number | Registry id (e.g. `1`) |

**Example**

```bash
curl http://localhost:8080/assets/1
```

Returns a single asset object with the schema above.

**Errors**

```json
{ "error": "not_found", "message": "no asset with id 999" }
```

Returned with status `404` when no asset has the given id. A non-numeric id
(`/assets/abc`) is rejected with `400` by the router.

<CalloutBox variant="tip">
`total_supply` and `valuation_cents` are strings. In JavaScript, parse them with
`BigInt(asset.total_supply)` and compute a display value as
`Number(BigInt(asset.total_supply)) / 10 ** asset.decimals`.
</CalloutBox>

## Client examples

### Go

Uses only `net/http` and `encoding/json` from the standard library. `total_supply` and
`valuation_cents` stay strings, so parse them with `math/big` if you need exact arithmetic.

```go
package main

import (
	"encoding/json"
	"fmt"
	"log"
	"net/http"
)

type Asset struct {
	ID             int     `json:"id"`
	TokenContract  string  `json:"token_contract"`
	Name           string  `json:"name"`
	Symbol         string  `json:"symbol"`
	AssetType      string  `json:"asset_type"`
	ValuationCents string  `json:"valuation_cents"`
	ValuationUSD   float64 `json:"valuation_usd"`
	Decimals       int     `json:"decimals"`
	TotalSupply    string  `json:"total_supply"`
	Holders        int     `json:"holders"`
	Active         bool    `json:"active"`
	Paused         bool    `json:"paused"`
}

func main() {
	resp, err := http.Get("http://localhost:8080/assets?asset_type=real_estate&active=true")
	if err != nil {
		log.Fatal(err)
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		log.Fatalf("unexpected status: %s", resp.Status)
	}

	var assets []Asset
	if err := json.NewDecoder(resp.Body).Decode(&assets); err != nil {
		log.Fatal(err)
	}

	for _, a := range assets {
		fmt.Printf("%s (%s): %d holders, $%.2f\n", a.Symbol, a.Name, a.Holders, a.ValuationUSD)
	}
}
```
