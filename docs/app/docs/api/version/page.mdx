# Version

<LastReviewed date={metadata.lastReviewed} />

`GET /version` returns the running service's crate version and a release label
derived from it. Use it to confirm which build is deployed.

## Request

```bash
curl -s https://<host>/version
```

## Response

```json
{
  "version": "0.1.0",
  "release": "v0.1.0"
}
```

| Field | Type | Nullable | Meaning |
| --- | --- | --- | --- |
| `version` | string | No | Crate version from `api/Cargo.toml`, e.g. `0.1.0` |
| `release` | string | No | `v` followed by `version`, e.g. `v0.1.0` |

The endpoint always returns `200` while the process is running. It does not
depend on indexer state, so use [`/health`](/docs/api/health) to check data
freshness.
