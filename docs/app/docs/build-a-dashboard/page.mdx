# Build a Dashboard

<LastReviewed date={metadata.lastReviewed} />

In this tutorial you build a one-file dashboard that shows the platform's total
value locked (TVL), active asset count, holder count and a table of every asset.
It reads two endpoints, `/v1/stats` and `/v1/assets`, and refreshes every 10
seconds, the same cadence the API's indexer uses.

You need the API running locally, as described in [Getting Started](/docs/getting-started),
and a browser. There is no build step and no framework.

## Step 1: Check the endpoints

With the API running on `localhost:8080`, confirm both endpoints answer:

```bash
curl http://localhost:8080/v1/stats
curl http://localhost:8080/v1/assets
```

`/v1/stats` returns one object. The dashboard uses `tvl_usd`, `active_assets`,
`total_assets`, `total_holders` and `last_indexed_ledger`. `/v1/assets` returns an
array. The dashboard uses `name`, `symbol`, `asset_type`, `valuation_usd`,
`holders`, `active` and `paused`.

<CalloutBox variant="note" title="The /v1 prefix">
Every data route is nested under `/v1`. Requests to `/stats` or `/assets` without the
prefix return `404`.
</CalloutBox>

## Step 2: Create the dashboard

Create a file named `dashboard.html` and paste in this code:

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Stellar RWA Dashboard</title>
  <style>
    body { font-family: system-ui, sans-serif; margin: 2rem; color: #111; }
    .kpis { display: grid; grid-template-columns: repeat(auto-fit, minmax(180px, 1fr)); gap: 1rem; margin-bottom: 2rem; }
    .kpi { border: 1px solid #ddd; border-radius: 8px; padding: 1rem; }
    .kpi span { display: block; font-size: 0.85rem; color: #555; }
    .kpi strong { font-size: 1.5rem; }
    table { border-collapse: collapse; width: 100%; }
    th, td { text-align: left; padding: 0.5rem; border-bottom: 1px solid #eee; }
    .num { text-align: right; }
    #error { color: #b00020; min-height: 1.2rem; }
    #updated { color: #555; font-size: 0.85rem; }
  </style>
</head>
<body>
  <h1>Stellar RWA Dashboard</h1>
  <p id="error" role="alert"></p>

  <section class="kpis">
    <div class="kpi"><span>Total value locked</span><strong id="tvl">—</strong></div>
    <div class="kpi"><span>Active assets</span><strong id="active">—</strong></div>
    <div class="kpi"><span>Holders</span><strong id="holders">—</strong></div>
    <div class="kpi"><span>Last indexed ledger</span><strong id="ledger">—</strong></div>
  </section>

  <table>
    <thead>
      <tr>
        <th>Asset</th><th>Type</th><th class="num">Valuation</th><th class="num">Holders</th><th>Status</th>
      </tr>
    </thead>
    <tbody id="assets"></tbody>
  </table>
  <p id="updated"></p>

  <script>
    const API = "http://localhost:8080/v1";
    const REFRESH_MS = 10_000;

    const usd = new Intl.NumberFormat("en-US", { style: "currency", currency: "USD", maximumFractionDigits: 0 });
    const count = new Intl.NumberFormat("en-US");
    const $ = (id) => document.getElementById(id);

    async function getJson(path) {
      const res = await fetch(API + path);
      const body = await res.json();
      if (!res.ok) throw new Error(`${path}: ${body.error} (${body.message})`);
      return body;
    }

    function renderStats(s) {
      $("tvl").textContent = usd.format(s.tvl_usd);
      $("active").textContent = `${s.active_assets} of ${s.total_assets}`;
      $("holders").textContent = count.format(s.total_holders);
      $("ledger").textContent = count.format(s.last_indexed_ledger);
    }

    function renderAssets(assets) {
      const rows = assets.map((a) => {
        const status = !a.active ? "Inactive" : a.paused ? "Paused" : "Active";
        const tr = document.createElement("tr");
        // textContent, never innerHTML: names and descriptions come from on-chain data.
        [
          [`${a.name} (${a.symbol})`, ""],
          [a.asset_type, ""],
          [usd.format(a.valuation_usd), "num"],
          [count.format(a.holders), "num"],
          [status, ""],
        ].forEach(([text, cls]) => {
          const td = document.createElement("td");
          td.textContent = text;
          td.className = cls;
          tr.appendChild(td);
        });
        return tr;
      });
      $("assets").replaceChildren(...rows);
    }

    async function refresh() {
      try {
        const [stats, assets] = await Promise.all([getJson("/stats"), getJson("/assets")]);
        renderStats(stats);
        renderAssets(assets);
        $("error").textContent = "";
        $("updated").textContent = `Updated ${new Date().toLocaleTimeString()}`;
      } catch (err) {
        // Keep the last good numbers on screen and say that they may be stale.
        $("error").textContent = `Could not load data: ${err.message}`;
      }
    }

    refresh();
    setInterval(refresh, REFRESH_MS);
  </script>
</body>
</html>
```

The script runs two requests in parallel with `Promise.all`, so the page waits for
the slower of the two rather than their sum.

## Step 3: Serve it from an allowed origin

Do not open `dashboard.html` with a `file://` URL. The browser sends a `null`
origin, and the API will not allow it. Serve the folder over HTTP instead:

```bash
cd path/to/dashboard
python3 -m http.server 5500
```

The API allows browser requests only from `http://localhost:3000` by default. That
is the docs site's dev server, so it will not work for a page on port `5500`. Add
your origin in `api/.env`, then restart `cargo run`:

```bash
# api/.env
RWA_CORS_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:5500
```

Open http://localhost:5500/dashboard.html. The four tiles fill in on the first
refresh, and the table lists every asset the API knows about.

<CalloutBox variant="warning" title="Check the CORS setting first">
If the tiles stay at `—` and the browser console shows a CORS error, the origin
serving the page is missing from `RWA_CORS_ALLOWED_ORIGINS`. Fix that before
debugging the code.
</CalloutBox>

## How it works

- **Amounts are numbers here, on purpose.** `tvl_usd` and `valuation_usd` are
  floats, which is fine for display. For exact arithmetic, use the string fields
  `tvl_cents` and `valuation_cents`, and parse them with `BigInt`. See
  [Assets](/docs/api/assets).
- **Untrusted text uses `textContent`.** Asset names and descriptions come from
  on-chain data that anyone can register. Inserting them with `innerHTML` would let
  a crafted name run script in your page.
- **Failures keep the old numbers.** If a refresh fails, the error appears above
  the tiles and the last good values stay on screen. A `404` or `400` returns a JSON
  body with `error` and `message`. See [Errors](/docs/api/errors).
- **Polling is steady, not bursty.** Each refresh makes two requests, one every
  10 seconds per open tab. If many visitors will keep the page open, raise
  `REFRESH_MS` and check the [Rate Limits & Caching](/docs/api/rate-limits) page.
