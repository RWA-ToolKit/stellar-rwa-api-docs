# Compliance Contract

<LastReviewed date={metadata.lastReviewed} />

Maintains the KYC allowlist and jurisdiction rules that gate who may hold or
transfer a tokenized asset. The asset-token contract calls
[`is_allowed`](#is-allowed) on every transfer (for both sender and recipient) and
on every mint (for the recipient).

Time is expressed in **ledger sequence numbers** (`u32`), not wall-clock dates. An
`expires_at` of `0` means the approval never expires.

**Testnet:** [`CBUERYDM7DXTZLLKDBRJKUBPFJ7M4OSUN4T7XKUARU345RLXNAIQD2IU`](https://stellar.expert/explorer/testnet/contract/CBUERYDM7DXTZLLKDBRJKUBPFJ7M4OSUN4T7XKUARU345RLXNAIQD2IU) — all addresses in [Getting Started → Deployed contract addresses](/docs/getting-started#deployed-contract-addresses-testnet)

## Data types

`ComplianceStatus` — `Approved` | `Pending` | `Rejected` | `Suspended`.

`KycRecord`:

| Field | Type | Notes |
|-------|------|-------|
| `address` | `Address` | The KYC'd account |
| `status` | `ComplianceStatus` | Only `Approved` passes the gate |
| `jurisdiction` | `String` | ISO country code, e.g. `US`, `KE`, `DE` |
| `verified_at` | `u32` | Ledger at verification |
| `expires_at` | `u32` | Ledger of expiry; `0` = never |

## Function reference

### `initialize`

```rust
fn initialize(env: Env, admin: Address)
```

Sets the admin. Callable once. **Auth:** `admin`. Errors: `AlreadyInitialized (1)`.

### `add_to_allowlist`

```rust
fn add_to_allowlist(
    env: Env, admin: Address, address: Address,
    jurisdiction: String, expires_at: u32,
)
```

Adds (or re-approves) an address, setting its status to `Approved`. If
`expires_at` is non-zero it must be a future ledger.

- **Auth:** `admin`
- **Errors:** `Unauthorized (5)`, `InvalidExpiry (4)` if `expires_at != 0 && expires_at <= now`.

### `add_to_allowlist_batch`

```rust
fn add_to_allowlist_batch(
    env: Env, admin: Address, addresses: Vec<Address>,
    jurisdiction: String, expires_at: u32,
) -> u32
```

Adds (or re-approves) many addresses in a single call, applying the same
`jurisdiction` and `expires_at` to each. Returns the number of records written.
Use this to onboard a batch of investors without one transaction per address.

- **Auth:** `admin`
- **Errors:** `Unauthorized (5)`, `InvalidExpiry (4)` if `expires_at != 0 && expires_at <= now`.

### `suspend`

```rust
fn suspend(env: Env, admin: Address, address: Address)
```

Sets an address's status to `Suspended`. The record is retained but `is_allowed`
returns `false` until it is re-approved. **Auth:** `admin`. Errors: `RecordNotFound (3)`.

### `remove`

```rust
fn remove(env: Env, admin: Address, address: Address)
```

Deletes the record entirely and drops the address from the allowlist. **Auth:**
`admin`. Errors: `RecordNotFound (3)`.

### `is_allowed`

```rust
fn is_allowed(env: Env, address: Address) -> bool
```

The core gate. Returns `true` **only if** the address is `Approved`, **and** not
expired (`expires_at == 0 || now < expires_at`), **and** its jurisdiction is not
blocked. Returns `false` for unknown addresses.

<CalloutBox variant="compliance" title="This is the gate">
Every check the RWA token performs funnels through `is_allowed`. Understanding its
three conditions — status, expiry, jurisdiction — is understanding the whole
compliance model. See the [Compliance Guide](/docs/compliance-guide).
</CalloutBox>

### `get_record` / `get_allowlist`

```rust
fn get_record(env: Env, address: Address) -> Option<KycRecord>
fn get_allowlist(env: Env) -> Vec<Address>
```

`get_record` returns `None` for an unknown address. `get_allowlist` returns every
address currently on the allowlist (any status except removed).

### `get_allowlist_page`

```rust
fn get_allowlist_page(env: Env, start: u32, limit: u32) -> Vec<Address>
```

Paginated variant of `get_allowlist`. Returns up to `limit` addresses beginning at
index `start`. Iterate with `start += limit` until a page returns fewer than
`limit` entries. Use this for large allowlists where the full `Vec` would exceed
response limits. Public read.

### `block_jurisdiction` / `unblock_jurisdiction` / `is_jurisdiction_blocked`

```rust
fn block_jurisdiction(env: Env, admin: Address, jurisdiction: String)
fn unblock_jurisdiction(env: Env, admin: Address, jurisdiction: String)
fn is_jurisdiction_blocked(env: Env, jurisdiction: String) -> bool
```

Blocking a jurisdiction makes **every** approved address in that jurisdiction fail
`is_allowed`, without touching individual records. **Auth:** admin for the mutating
calls.

### `status_of`

```rust
fn status_of(env: Env, address: Address) -> ComplianceStatus
```

Returns the current status for an address. Unknown addresses are `Rejected`;
expiry and jurisdiction blocking are evaluated by `is_allowed`, not by changing
the stored status. This is a read-only call and requires no authorization.

### `prune_expired`

```rust
fn prune_expired(env: Env, admin: Address, limit: u32) -> u32
```

Removes up to `limit` expired records and returns the number removed. It is an
optional storage-maintenance operation: expiry already makes an address fail
`is_allowed` immediately, so pruning does not change transfer authorization.
**Auth:** `admin`. Use a bounded limit and repeat the call for large allowlists.

### `set_min_holding_period` / `min_holding_period`

```rust
fn set_min_holding_period(env: Env, admin: Address, ledgers: u32)
fn min_holding_period(env: Env) -> u32
```

Sets (and reads) a minimum holding period, in ledgers, that a holder must wait
after acquiring the asset before transferring it. `0` disables the check. The
asset-token contract consults this value on transfers. **Auth:** `admin` for
`set_min_holding_period`; `min_holding_period` is a public read.

### `set_dividend_deadline` / `reclaim_dividend` / `cancel_dividend`

```rust
fn set_dividend_deadline(env: Env, admin: Address, dividend_id: u64, deadline: u32)
fn reclaim_dividend(env: Env, admin: Address, dividend_id: u64) -> i128
fn cancel_dividend(env: Env, admin: Address, dividend_id: u64)
```

Manage the lifecycle of a declared dividend. `set_dividend_deadline` sets the
ledger after which unclaimed funds may be reclaimed. `reclaim_dividend` returns
unclaimed funds to the treasury after the deadline and returns the amount
reclaimed. `cancel_dividend` cancels a dividend before distribution. **Auth:**
`admin` for all three.

### `transfer_admin` / `accept_admin`

```rust
fn transfer_admin(env: Env, admin: Address, new_admin: Address)
fn accept_admin(env: Env, new_admin: Address)
```

Two-step admin handover. `transfer_admin` nominates a `new_admin`; the nominee
must then call `accept_admin` to complete the handover. Until accepted, the
current admin remains in control. **Auth:** current `admin` for `transfer_admin`;
`new_admin` for `accept_admin`.

### Authority summary

| Method | Authority |
|---|---|
| `initialize` | The supplied admin signs once |
| `add_to_allowlist`, `add_to_allowlist_batch`, `suspend`, `remove` | Stored admin |
| `block_jurisdiction`, `unblock_jurisdiction`, `prune_expired` | Stored admin |
| `set_min_holding_period`, `set_dividend_deadline`, `reclaim_dividend`, `cancel_dividend` | Stored admin |
| `transfer_admin` | Stored admin |
| `accept_admin` | Nominated new admin |
| `is_allowed`, `get_record`, `status_of`, `get_allowlist`, `get_allowlist_page`, `is_jurisdiction_blocked`, `min_holding_period` | Public read |

`ComplianceStatus` values are `Approved` (passes when unexpired and not blocked),
`Pending` (verification is incomplete), `Rejected` (not approved), and
`Suspended` (temporarily disabled). Only `Approved` can pass the gate.

## Worked example

This example runs against the current Testnet deployment
(`CBUERYDM7DXTZLLKDBRJKUBPFJ7M4OSUN4T7XKUARU345RLXNAIQD2IU`). It approves an
investor in the US with a one-year expiry (~6.3M ledgers at 5s each), reads the
record back, and confirms the gate passes.

```ts
import {
  Contract,
  Keypair,
  Networks,
  TransactionBuilder,
  nativeToScVal,
  scValToNative,
  rpc,
  Address,
} from "@stellar/stellar-sdk";

const COMPLIANCE_ID = "CBUERYDM7DXTZLLKDBRJKUBPFJ7M4OSUN4T7XKUARU345RLXNAIQD2IU";
const server = new rpc.Server("https://soroban-testnet.stellar.org");
const networkPassphrase = Networks.TESTNET;

// The admin keypair that controls the Testnet compliance contract.
const admin = Keypair.fromSecret(process.env.ADMIN_SECRET!);
const investor = Keypair.random().publicKey();

const compliance = new Contract(COMPLIANCE_ID);

async function submit(op: ReturnType<Contract["call"]>, signer: Keypair) {
  const account = await server.getAccount(signer.publicKey());
  const tx = new TransactionBuilder(account, {
    fee: "1000000",
    networkPassphrase,
  })
    .addOperation(op)
    .setTimeout(30)
    .build();
  tx.sign(signer);
  const sent = await server.sendTransaction(tx);
  return server.pollTransaction(sent.hash);
}

// 1. Approve the investor for one year (~6.3M ledgers at 5s each).
const latest = await server.getLatestLedger();
const expiresAt = latest.sequence + 6_300_000;

await submit(
  compliance.call(
    "add_to_allowlist",
    nativeToScVal(admin.publicKey(), { type: "address" }),
    nativeToScVal(investor, { type: "address" }),
    nativeToScVal("US", { type: "string" }),
    nativeToScVal(expiresAt, { type: "u32" }),
  ),
  admin,
);

// 2. Read the record back.
const record = await server.getContractData(
  COMPLIANCE_ID,
  nativeToScVal(investor, { type: "address" }),
);
console.log(scValToNative(record.val));
// { address: 'G…', status: 'Approved', jurisdiction: 'US',
//   verified_at: <ledger>, expires_at: <ledger> }

// 3. Confirm the gate passes (public read — no signature needed).
const allowed = await server.simulateTransaction(
  new TransactionBuilder(await server.getAccount(admin.publicKey()), {
    fee: "1000000",
    networkPassphrase,
  })
    .addOperation(
      compliance.call(
        "is_allowed",
        nativeToScVal(investor, { type: "address" }),
      ),
    )
    .setTimeout(30)
    .build(),
);
console.log(scValToNative(allowed.result!.retval)); // true
```

To revoke access, call `suspend` (retains the record) or `remove` (deletes it):

```ts
await submit(
  compliance.call(
    "suspend",
    nativeToScVal(admin.publicKey(), { type: "address" }),
    nativeToScVal(investor, { type: "address" }),
  ),
  admin,
);
```

<CalloutBox variant="note" title="Verified against Testnet">
The contract ID, function names, and argument types above match the current
Testnet deployment. If a call fails with `InvalidExpiry (4)`, the `expires_at`
ledger has already passed — recompute it from `getLatestLedger()`.
</CalloutBox>
